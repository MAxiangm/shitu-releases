# 3D 模型支持

从拾图 0.11.0 起，可把模型文件或整个项目文件夹拖入素材库。模型与找到的依赖作为一份资产保存，原件保持不变。

| 格式 | 收集的资源 | 预览方式 |
| --- | --- | --- |
| GLB / glTF | 内嵌资源、外置 BIN、图片与压缩贴图 | 应用内直接预览 |
| OBJ | OBJ、MTL、引用贴图 | 应用内直接预览 |
| FBX | 原模型、嵌入图片、找到的外置贴图 | 应用内直接预览 |
| STL / PLY | 网格或点云 | 应用内直接预览 |
| BLEND | 原工程、附近贴图与可选预览侧车 | 本机 Blender 转换，或使用侧车 |
| C4D | 原工程、附近贴图与可选预览侧车 | 本机已授权 Cinema 4D 的 c4dpy 转换，或使用侧车 |
| MAX | 原工程、附近贴图与可选预览侧车 | 本机已授权 3ds Max Batch 转换，或使用侧车 |

## 使用

1. 拖入模型；模型引用上级目录中的贴图时，拖入包含模型与贴图的共同项目文件夹。
2. 双击模型，左键旋转、滚轮缩放、右键平移；工具栏可重置视角或查看线框。有动画的模型可播放动画。
3. 详情面板显示资源包文件数、大小与缺失引用。导出或向资源管理器拖出，会得到包含模型与依赖的独立目录。

普通模型的引用资源按照目录结构保存，不改写源模型。单独明确选中的图片仍可作为独立图片导入；从项目文件夹导入时，属于模型包的贴图不在画廊中重复出现。

## 原生工程

应用自动寻找 Program Files 中的 Blender、Cinema 4D 和 3ds Max。没有对应软件或后台软件未获授权时，原件仍可导入，预览界面会说明原因。应用不会处理软件登录或许可。

可通过启动进程环境变量指定非标准安装位置：`SHITU_BLENDER`、`SHITU_C4DPY`、`SHITU_3DSMAXBATCH`，值为对应可执行文件的绝对路径。转换使用项目自带的固定脚本，只输出本地兼容预览缓存，不覆盖原工程。

也可以在 `chair.c4d`、`chair.blend` 或 `chair.max` 旁放一个对应的 `chair.glb`、`chair.gltf`、`chair.fbx` 或 `chair.obj`。该侧车和它的资源一起打包，用于预览，导出保留原生工程。

私有原工程无法仅靠文件头完整解析全部依赖。应用收集同目录贴图及 `tex`、`textures`、`maps`、`images`、`materials`、`sourceimages`、同名 `.fbm` 等常见目录。工程引用其他磁盘或位置的图像、链接模型、第三方渲染器材质和插件可能缺失，界面会保留相关提醒。复杂项目应先使用原软件的资源收集功能，把依赖集中到项目文件夹后再导入。

模型资源不通过网络加载。GLB 中的 Draco、Meshopt 与 KTX2 使用随应用附带的离线解码器。原生转换由本机建模软件执行，其插件和系统环境可能影响结果。

## 数据与兼容

模型原件和依赖保存在 `originals/<资产ID>.model/`，清单写入素材库索引；清单包含相对路径、大小及 SHA-256。去重同时比较贴图内容，修改贴图后的同名模型可以再次导入。备份、迁移、回收站和导出会处理整个资源包。

已有图片和视频索引继续使用。加入模型后，该素材库需要 0.11.0 或更新版，0.10.10 及更早版本会拒绝读取包含新格式的索引并保留原文件。

## 依赖与验证

预览使用 MIT 许可的 Three.js 0.187.0 及其附带组件，详见 [源码与许可说明](../src/vendor/three/README.md)、[Three.js 许可证](../src/vendor/three/LICENSE) 和 [第三方组件许可](../src/vendor/three/THIRD_PARTY_LICENSES.txt)。Blender、Cinema 4D 和 3ds Max 均由用户自行安装，不包含在拾图安装包中。

原生桥接依据 [Maxon c4dpy 文档](https://developers.maxon.net/docs/py/2026_1_0/manuals/manual_py_c4dpy.html) 与 [Autodesk Batch 文档](https://help.autodesk.com/cloudhelp/2025/ENU/3DSMax-Batch/files/GUID-48A78515-C24B-4E46-AC5F-884FBCF40D59.htm)。

开发验证命令：`node scripts/prepare-model-test-fixtures.cjs`、`node scripts/smoke-model-viewer.cjs`、`node scripts/smoke-model.cjs`。本机原生软件可额外运行 `node scripts/prepare-native-model-fixtures.cjs blend,c4d,max`；样例与测试库均位于 `.recovery/tests`。
