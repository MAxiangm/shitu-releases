# Mosaic 采集助手 0.11.33

1. 安装并打开 Windows 版 Mosaic，选择或新建素材库。
2. 在 Chrome 地址栏打开 `chrome://extensions`，打开「开发者模式」，点「加载已解压的扩展程序」，选择此文件夹（这里应能直接看到 `manifest.json`）。
3. 点击浏览器工具栏的 Mosaic 图标，在「保存到」选择目标文件夹。采集助手会分别记住每个素材库的选择。
4. 回到网页并刷新。按住 **Alt**，用鼠标**右键**点击播放器、视频文件链接或图片，即可下载原文件到 Mosaic。也可使用图片或视频的普通右键菜单「保存到 Mosaic」。

扩展会自动连接本机运行中的 Mosaic，并使用当前素材库。可点扩展图标查看状态，故障时点「重新检测」。Chrome 的内置页面、扩展商店和部分受保护页面不允许内容脚本工作。

网页会显示读取、连接、下载和入库状态。下载时可查看已传输大小，服务器提供总大小时会显示比例。收到素材库确认后，可在网页提示或采集助手的「上次采集结果」中点「在 Mosaic 中查看」，直接定位到素材。重复采集会定位已有素材。如果原素材库已经切换，请在 Mosaic 里切回采集时使用的库。

## 从旧版升级

1. 安装 Mosaic，并将此扩展文件夹更新到 0.11.33。
2. 在 `chrome://extensions` 找到已安装的采集助手，点「重新加载」。如果原来加载的是下载目录中的旧副本，请从 Mosaic 的「浏览器采集」打开扩展目录，并载入该目录里的新版。
3. 刷新之前已打开的素材网页，再用 Alt＋右键测试。已注入旧内容脚本的页面必须刷新。

扩展弹窗会核对运行中后台脚本的固定构建版本；发现旧后台时尝试重新加载。弹窗底部可查看采集助手版本。

## Sketchfab 模型

桌面需要 Mosaic **0.29.30** 或更新版本。沿用当前 Chrome 中的 Sketchfab 网页登录，无需复制 API Token。若尚未登录，请直接在原来的 Sketchfab 页面完成登录；Mosaic 不会自动打开独立登录窗口。

刷新模型页面后，在 Sketchfab 模型画布、嵌入查看器或模型卡片上按 **Alt＋右键**。采集助手通过官网同源下载流程取得作者开放下载的 glTF ZIP，Mosaic 将模型、二进制、贴图、许可证和署名信息作为一个模型资源包保存到所选素材库文件夹，可直接预览和导出。重复采集会提示已存在并提供定位。

无法取得官网下载文件时，采集助手会尝试保存当前页面已经显示的模型：几何体、法线、UV、底色，以及已识别的金属度、粗糙度、法线贴图、环境遮蔽和发光通道封装为 GLB，再交给 Mosaic 入库。合并贴图按原着色器的通道拆分，粗糙度等数据不会被当成透明度。可识别的骨骼权重、层级和原始动画关键帧也会保留，Mosaic 预览可播放动画。必须先刷新页面并等待模型完整显示；模型卡片本身没有载入查看器时需要先打开模型页。变形、实例化和未知动画结构会明确拒绝不完整导出，未识别的材质公式会显示警告。

压缩包上限 512 MB，展开后上限 1 GB；网页采集最多 300 万个完整属性顶点、512 个网格及 384 MiB 传输数据；单张纹理最高 8192×8192，图片合计最多 96 MiB / 64M 像素，输出 GLB 最多 256 MiB。大型快照按 4 MiB 分块传递。来源变化、必要数据缺失或不支持的绘制方式会显示具体原因。登录 Cookie 和 CSRF 凭据不会传给桌面；临时签名下载地址只供当前任务使用，不写入素材信息。

## YouTube

在采集助手弹窗点击「使用当前 YouTube 登录」，确认 Chrome 的可选授权后，下载会使用当前视频标签页所属 Chrome 账号，无需在新窗口重新登录。每次下载仅临时传递 YouTube 会话给本机 Mosaic，结束后清理；不会把登录数据写入采集记录、素材信息或浏览器同步存储。可在弹窗点击「停用当前 YouTube 登录」撤回此功能，不影响 Bilibili 的授权。桌面需要 0.29.24 或更新版本。

现有的浏览器播放文件后备通路仍会按条件使用；当前未启用录制功能。

- 在普通视频、Shorts 或嵌入播放器上按 **Alt＋右键**，或右键选择「下载 YouTube 视频到 Mosaic」。视频卡片链接也支持这两种操作。
- 保存的是视频文件，沿用采集助手中选择的目标文件夹；音视频分开时自动合并，保留来源页面和标题。下载进度与保存结果会显示在网页和采集助手中。
- 桌面下载遇到授权、网络或来源不可用错误时，会尝试通过当前浏览器读取同一视频。仅当页面已观察到可读取的标准 MP4/WebM 完整音视频源时启用，分开的音视频自动合并，合计上限 512 MB；不会仅凭播放器正在播放就报告下载成功。
- 浏览器回退暂不支持 SABR/UMP；页面只有这些播放源时会保留失败提示。桌面端需包含新版 YouTube 下载组件；直播、付费、受保护视频或没有可读取授权来源的视频会提示原因。

## Instagram、X 和 Vimeo

- Instagram 和 X：打开单条 Reel 或视频帖子，在视频画面上按 Alt＋右键。页面提供对应的完整视频文件时，会沿用「保存到」中的目标文件夹和定位回执。
- Instagram 和 X 的播放器遮罩、站内弹窗与首次播放源切换均支持 Alt＋右键。X 还会在本页读取播放器已收到的公开帖子视频信息，以覆盖登录后的动态加载；不读取私信接口。
- X 以按下快捷键时的媒体身份为准；播放器随后重新渲染或切换画面时，仍保存最初选中的视频。
- X 支持普通视频记录及多视频卡片内的视频记录，按实际选中的画面选择文件。
- Vimeo：普通视频页和嵌入播放器均可采集。先播放视频，再在画面上右键选择「保存到 Mosaic」，或直接按 Alt＋右键。Mosaic 支持播放器提供的可读取完整文件，以及支持格式中的未加密 HLS 和 DASH 点播。分开的画面和声音会直接合并为 MP4，保留原有编码。作者开放的「下载」菜单仍可选择具体版本。
- Vimeo 下载返回 401/403 时，采集助手会尝试通过当前浏览器分块读取同一播放源，再交给桌面合并入库。此路径同样支持最高 512 MB，不受普通临时视频 20 MB 的限制；仍需网站允许浏览器读取该媒体，不会绕过跨域、登录或加密限制。
- 播放源需要能从本机读取，视频采集上限为 512 MB。遇到人机验证、登录限制、直播或受保护的视频，采集会报告原因。

## 在 Pinterest 测试

更新后先在 `chrome://extensions` 重载采集助手，再刷新 Pinterest 页面。打开单个 Pin，在图片、视频画面或视频封面上按 Alt＋右键。视频也可以普通右键，选择「保存到 Mosaic」。等出现「已保存到素材库」，再到 Mosaic 的「最近导入」核对。

图片采集使用当前页面显示的 `pinimg.com` 地址。视频采集会识别该 Pin 页面声明的完整 MP4，并核对所选画面或封面是否与素材匹配。图片优先由浏览器按同源与 CORS 规则读取，还可交由桌面下载。

从站内其他页面进入视频 Pin 时，若当前文档没有保留视频源数据，采集助手会按需读取这个 Pin 的详情页，匹配当前画面后保存完整视频，无需先手动刷新。

## 图片和视频范围

- 采集当前实际显示的图片地址（含 `picture`、CSS 背景图及不超过 20 MB 的临时 blob/data 图片）。不自动猜测或改写网站的高清链接。
- 视频支持可直接读取的 HTTP/HTTPS 文件，例如 MP4、WebM；完整 Blob/data 视频在 20 MB 内也可读取。YouTube 点播视频和受支持的 Vimeo 播放源可自动下载并合并音视频。
- Instagram、X、Pinterest 和 Vimeo 的直链不可用或下载结果不完整时，可自动尝试已确认的所选帖子页面，由桌面提取并合并完整音视频。无法确认所选视频或多视频卡片中的具体对象时，不猜测其他帖子或视频。
- 桌面优先下载视频直链（上限 512 MB）。遇到登录或授权响应时，扩展可在当前网页读取浏览器已经有权访问的视频文件（上限 20 MB）。
- HTTP 图片优先由当前网页的浏览器上下文读取，受同源策略约束；同源请求可以使用浏览器现有登录会话，跨域请求不携带 Cookie。扩展不会为图片采集读取 Cookie。只有你主动开启 YouTube 或 Bilibili 登录授权后，下载对应网站视频时才读取该域的会话。
- 浏览器读取图片以流式方式限制在 20 MB 内。遇到 CORS、超时、不支持的响应或大图时，退回桌面直链下载（上限 512 MB）。Blob/data 素材必须能在网页中读取，仍以 20 MB 为硬上限。
- 需要特殊防盗链、授权或网站脚本的素材仍可能失败；扩展不会绕过付费、登录、DRM 或浏览器的同源限制。
- 去重由桌面素材库完成，采集成功时保留网页来源和标题。
- 视频入库前检查可读取的视频轨；来源提供声音和时长信息时，还会核对音轨与总时长。缺少应有声音或时长不符的结果不会显示保存成功。
- 同一素材正在采集时的重复操作共享保存结果。扩展保存最后一次结果和当前处理状态；若超过五分钟未收到回执，弹窗会提示先在桌面核对，避免误报成功。

## 权限与隐私

- 网页内容脚本：只为识别你 **Alt＋右键** 选中的素材、显示结果提示。未触发采集时不向桌面程序发送网页内容。
- 自动发现及采集只连接 `127.0.0.1` 的 `38475–38484` 端口，不扫描局域网，不连接其他电脑。
- `storage`：保存本机连接信息与上次操作结果；不使用浏览器同步存储。内部鉴权信息仅扩展后台可读，不向网页或弹窗公开。
- `contextMenus`：提供「保存到 Mosaic」右键菜单。
- 默认不申请 Cookie 权限；YouTube 和 Bilibili 分别申请可选 cookies 权限与 https://*.youtube.com/* 或 https://*.bilibili.com/* 访问权限。仅在你触发对应网站下载时读取当前标签页所属 cookie store，两站会话互不混用，不读取 Google 或其他网站的 Cookie。不申请浏览历史、下载列表或浏览器调试权限，不向任何云端上传数据。

## Bilibili

- 在 Bilibili 视频画面、视频卡片或视频链接上按 **Alt＋右键**，使用桌面下载通路保存所选视频。BV 号、av 号和 `p` 分集会一并校验；没有明确分集的链接按第 1 集处理，不会自动下载整套合集。
- 在采集助手中开启「使用当前 Bilibili 登录」，即可复用当前 Chrome 已登录账号，无需打开新登录窗口。YouTube 与 Bilibili 可独立开启、停用；只有两站均停用时才移除共用的可选 Cookie 权限。未开启时可尝试公开下载。完成下载、音视频合并与文件检查后才会显示保存结果。
- `b23.tv` 短链接需先在浏览器跳转到明确的 Bilibili 视频页面。直播、番剧及无法确定视频或分集的卡片不由此入口猜测下载。
