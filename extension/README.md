# 拾图采集助手 0.6

1. 安装并打开 Windows「拾图」，选择或新建素材库。
2. 在 Chrome 地址栏打开 `chrome://extensions`，打开「开发者模式」，点「加载已解压的扩展程序」，选择此文件夹（这里应能直接看到 `manifest.json`）。
3. 回到网页并刷新。按住 **Alt**，用鼠标**右键**点击图片或可下载的视频，即可导入拾图。也可使用图片/视频的普通右键菜单「保存到拾图」。

扩展会自动发现本机运行中的拾图，自动连接并跟随当前素材库，无需填写地址、端口或其他配置。换电脑后也会自动发现该电脑上的拾图。桌面软件必须处于运行状态；可点扩展图标查看状态，故障时点「重新检测」。Chrome 的内置页面、扩展商店和部分受保护页面不允许内容脚本工作。

## 图片和视频范围

- 采集当前实际显示的图片地址（含 `picture`、CSS 背景图及不超过 20 MB 的临时 blob/data 图片）。不自动猜测或改写网站的高清链接。
- 视频支持可直接下载的 HTTP/HTTPS 文件，例如 MP4、WebM；完整 Blob/data 视频在 20 MB 内也可读取。由 MediaSource 产生的分段流、直播、DRM 视频不能通用下载；遇到此类资源会明确提示失败，不会保存一个假视频文件。
- 需要浏览器 Cookie、防盗链校验或登录授权的素材可能无法下载。扩展不读取 Cookie，也不绕过网站的付费、登录或 DRM 限制。
- 去重由桌面素材库完成，采集成功时保留网页来源和标题。

## 权限与隐私

- 网页内容脚本：只为识别你 **Alt＋右键** 选中的素材、显示结果提示。未触发采集时不向桌面程序发送网页内容。
- 自动发现及采集只连接 `127.0.0.1` 的 `38475–38484` 端口，不扫描局域网，不连接其他电脑。
- `storage`：保存本机连接信息与上次操作结果；不使用浏览器同步存储。内部鉴权信息仅扩展后台可读，不向网页或弹窗公开。
- `contextMenus`：提供「保存到拾图」右键菜单。
- 不申请 Cookie、浏览历史、下载列表或浏览器调试权限；不向任何云端上传数据。
