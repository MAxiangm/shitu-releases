从网页，拾取灵感

使用 Mosaic 的 Chrome 扩展，将网页上的图片、视频和 Sketchfab 模型保存到本地素材库。

正在检查本地接收服务…

扩展安装后自动连接本机，无需输入连接码。

  1. 找到扩展目录点击下方「打开扩展目录」，记下文件夹位置。
  2. 在 Chrome 加载扩展打开 chrome://extensions，开启「开发者模式」，选择「加载已解压的扩展程序」，然后选中刚才的扩展文件夹。首次加载完成即可使用。
  3. 直接采集到素材库在采集助手弹窗选择保存到哪个文件夹。在网页素材上按住 Alt 并点击右键，保存后点击「在 Mosaic 中查看」即可定位。

使用当前 Chrome 的网站登录

YouTube 和 B 站沿用当前 Chrome 视频页面的账号，无需打开新窗口或重新登录。首次使用分别在采集助手中授权；可随时停用。

在 Chrome 工具栏打开 Mosaic 采集助手，分别开启 YouTube 或 B 站登录授权。

Sketchfab 模型下载

在当前 Chrome 打开 sketchfab.com/settings/password，复制自己的 API Token 并在此连接一次，即可采集作者开放官方下载的模型。

Token 仅由本机系统加密保存，可随时断开；不会打开新的登录窗口。
